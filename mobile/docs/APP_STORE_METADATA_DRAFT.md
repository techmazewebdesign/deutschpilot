## English listing draft

Name: DeutschPilot: Learn German

Subtitle: Daily German & vocabulary

Description:

Build a daily German-learning routine with short lessons, vocabulary review and self-tests.

Choose a practice level from A1 to C1, set a daily goal and continue with your next lesson. Read examples, check your understanding and review words in small sessions.

The app includes 105 lessons, 684 vocabulary cards, local progress, spaced vocabulary review, short quizzes, listening practice using a German system voice, and light/dark appearance. The interface is currently in German; many learning items include English translations or explanations.

Bundled learning content can be opened without an account. Pronunciation requires an available German system voice. Account functions require internet access. Learning progress stays on this device and does not synchronize with the website.

Level labels organize practice content. The app does not issue recognized language certificates or replace an official language examination.

## Reviewer notes draft

- Native Expo/React Native app; no remote WebView interface.
- All bundled learning features can be explored as a guest. No paid digital purchasing interface is provided in this candidate.
- Start on Today, choose a level and open a lesson. Read the material, take the self-test and finish after answering its questions. New lessons award 20 local XP once; repeats count as study activity without duplicate XP.
- Words: search by German/English/topic or start a ten-card review. Reveal the translation before rating recall.
- Practice: choose a short knowledge test or listening round. TTS uses the system's German voice, not microphone recording or speech recognition.
- Account: optional email/password signup, verification and password recovery. Google sign-in is hidden on iOS while Apple-provider configuration/testing remains incomplete.
- Account deletion is under Account and requires the exact typed phrase shown. Live verification of the complete backend deletion must be done before these notes can claim it works end to end.
